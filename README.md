# Calculadora de Frete

## Descrição
Programa desenvolvido em Python para calcular
o valor do frete de um pacote de acordo com seu peso.

## Regras de Frete
- Até 5 kg: R$ 20,00
- Acima de 5 kg até 20 kg: R$ 35,00
- Acima de 20 kg: R$ 60,00

## Como executar
1. Instale o Python.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:

   python frete.py
